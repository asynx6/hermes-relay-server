# Example crontab for Hermes Agent (incoming message polling).
#
# Install: crontab -e, then copy the lines below (adjust the paths).
# Logs are stored in data/cron.log so they can be audited if something goes wrong.

# --- Incoming messages (GET /fetch-messages) every minute --------------------
* * * * * /home/user/hermes-agent/skill/examples/fetch-once.sh >> /home/user/hermes-agent/data/cron.log 2>&1

# --- Alternative: every 5 minutes (cheaper, message latency up to 5 minutes) --
# */5 * * * * /home/user/hermes-agent/skill/examples/fetch-once.sh >> /home/user/hermes-agent/data/cron.log 2>&1

# --- Alternative: every minute during working hours only ---------------------
# * 8-18 * * 1-5 /home/user/hermes-agent/skill/examples/fetch-once.sh >> /home/user/hermes-agent/data/cron.log 2>&1

# Notes:
# - Cron minimum interval is 1 minute. For faster polling (seconds),
#   run a long-running process: nohup python -m hermes.main poll >> data/poll.log 2>&1 &
# - Do not run cron AND a long-running process for the same agent; the cursor
#   last_message_id can race and messages can be missed.
# - fetch-once exit code: 0=ok, 1=server down, 2=token rejected (401).
#   If the system sends email for exit != 0, the alert is immediately meaningful.
# - The log keeps growing; rotate it with logrotate or clear it periodically:
#   0 0 * * 0 truncate -s 0 /home/user/hermes-agent/data/cron.log
